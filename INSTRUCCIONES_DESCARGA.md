# 📱 Instrucciones para Descargar el Proyecto en tu Teléfono

## 🎯 Opción 1: Descargar como ZIP (MÁS FÁCIL)

### En tu navegador móvil:

1. **Abre tu navegador** (Chrome, Safari, etc.)
2. **Ve a la URL del repositorio:**
   ```
   https://github.com/Franeldramatico/AgendaProElite
   ```
3. **Toca el botón verde "Code"** (en la parte superior derecha)
4. **Selecciona "Download ZIP"**
5. **Espera a que termine la descarga**
6. **Extrae el archivo ZIP** usando un gestor de archivos

### Ubicación del archivo:
- **Android**: Generalmente en la carpeta `Downloads`
- **iOS**: En la app Archivos, carpeta Descargas

---

## 📲 Opción 2: Usar la App de GitHub

### Pasos:

1. **Instala la app "GitHub"** desde:
   - Play Store (Android)
   - App Store (iOS)

2. **Inicia sesión** con tu cuenta de GitHub

3. **Busca el repositorio:**
   - Toca el ícono de búsqueda 🔍
   - Escribe: `Franeldramatico/AgendaProElite`

4. **Abre el repositorio**

5. **Descarga el proyecto:**
   - Toca los **tres puntos (⋮)** en la esquina superior derecha
   - Selecciona **"Download ZIP"**

---

## 💻 Opción 3: Clonar con Git (Para usuarios avanzados)

### Requisitos:
- **Android**: App **Termux** (disponible en F-Droid o Play Store)
- **iOS**: App **iSH** (disponible en App Store)

### Comandos en Termux (Android):

```bash
# Instalar Git (si no está instalado)
pkg install git

# Navegar a la carpeta donde quieres clonar
cd ~/storage/downloads

# Clonar el repositorio
git clone https://github.com/Franeldramatico/AgendaProElite.git

# Entrar al proyecto
cd AgendaProElite

# Ver los archivos
ls -la
```

### Comandos en iSH (iOS):

```bash
# Instalar Git
apk add git

# Clonar el repositorio
git clone https://github.com/Franeldramatico/AgendaProElite.git

# Entrar al proyecto
cd AgendaProElite
```
